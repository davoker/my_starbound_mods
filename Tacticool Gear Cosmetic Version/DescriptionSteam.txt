I wanted a cosmetic version of the original mod, and the author give me permission to do the same as with the previous cosmetic, which you can find here:

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=2951621536] SWAT Raid Gear Cosmetic Version[/url]

So now I'm doing the same with this mod. I did this for myself, just like the previous SWAT mod. If you're like me and would like them to be cosmetics for whatever reason, this is for you too. [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2951621536] Voodoo's Child[/url] sprites are amazing.

[h1]Changes in the mod[/h1]
[list]
[*] The clothing is no longer [b]active[/b], i.e. it does not give attack, defense, energy... it is now completely cosmetic, this is what it is based on.
[*] Minor change -> a more suitable sprite for the vending machine
[/list]

[h1]Other information[/h1]
[list][*]Nearly 130 pieces of military style equipment.
[*]The vending machine can be obtained from the Architect's Table, which is the highest level of the Inventor's Table, for 5000 pixels.
[*]Common clothing costs 2500, uncommon 5000, rare 7500, and legendary 10000. It's expensive because I want it to be expensive; it's Tacti[b]cool[/b] clothing (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧ [/list]

[b]The mod comes as it comes, there are no plans to update anything, just some modifications of the original mod.[/b]
