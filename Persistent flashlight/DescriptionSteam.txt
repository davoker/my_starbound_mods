[h1]Description, or something like this[/h1]
Every time you holstered your weapon, the flashlight turned off and forgot its state. This mod makes it remember.

[list]
[*]If you leave the flashlight on and holster the weapon, when you draw it again, it turns back on.
[*]If you leave it off, it stays off when drawn.
[*]It works with any weapon that uses the original game flashlight, including modded weapons.
[*]It does not modify original files; a new LUA file is created and flashlight.weaponability is patched to call it. The functionality of the original LUA file that modifies the flashlight's behavior remains operational.
[/list]

[h1]Compatibility[/h1]
The [url=https://steamcommunity.com/sharedfiles/filedetails/?id=743648486] Flashlight, stay on!!![/url] mod is redundant as it performs the same function as this mod, with the difference that my mod does not replace the original LUA file.

- It should be compatible with everything, since a new file is created.
